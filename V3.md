# Unified Build Standard — version 3

**Status:** release candidate on the `v3` branch. Version 2.0 on `main` remains the published standard until v3 has been proven on real work.

Version 3 is a self-contained skill: [`skill/build-standard-v3/`](skill/build-standard-v3/). It does not depend on `BUILD_STANDARD.md`.

## What changed from v2

| | v2 | v3 |
| --- | --- | --- |
| Starting point | A plan | A measurable goal: what, how it is measured, limits, when to stop |
| Run modes | Phase gate; uninterrupted only through `/away` (time-boxed) | Gated or Unattended, chosen in the goal |
| The plan | One 15-column table for both owner and executor | A plain-English table for the owner, plus one work order file per step for the executor |
| Progress record | `EXECUTION_PROGRESS.md` | A "Now" section that is rewritten, and a run log that is only added to |
| Where records live | Project root | `build-plan/` in every project |
| Cross-model handoff | Packet for the active step only | Work orders written ahead, with a README any model can follow |
| Size | 511 lines read in full each time | 143 lines of core rules; detail loaded when needed |

## Layout

```
skill/build-standard-v3/
├── SKILL.md                     the standard: core rules
├── references/planning.md       writing the goal, plan table and work orders
├── references/tools.md          Claude Code, Codex, Kimi; unattended runs; model tiers
├── templates/build-plan/        GOAL.md, PLAN.md, LOG.md, README.md, steps/STEP_TEMPLATE.md
└── scripts/new-build-plan.sh    creates build-plan/ in a project
```

## Install

**Claude account (web, desktop app, mobile, cloud sessions, Claude Code).** Upload [`dist/anthropic/build-standard-v3.zip`](dist/anthropic/build-standard-v3.zip) at claude.ai → Plugins → Add → Upload plugin. Invoke with `/build-standard-v3`.

**One machine, by symlink (Claude Code, Codex, Kimi).** Check out this branch, then:

```bash
ln -s "$PWD/skill/build-standard-v3" ~/.claude/skills/build-standard-v3
ln -s "$PWD/skill/build-standard-v3" ~/.agents/skills/build-standard-v3
```

## Use

In a project, say: "Use build standard v3. My goal is …". Give a way to measure the goal if you have one; otherwise the model proposes one. Say whether the run is Gated or Unattended.

## Updating

Edit files under `skill/build-standard-v3/`, then run `python3 scripts/package_skill.py` to rebuild the ZIP and `python3 scripts/package_skill.py --check` to verify. Commit and push. Symlinked installs update at once; the Claude account copy needs the new ZIP uploaded again.

## Promotion to main

When v3 has passed its trial: merge this branch into `main`, decide whether the skill keeps the name `build-standard-v3` or takes over `unified-build-standard`, add it to the OpenAI plugin, and update the root `README.md`.
