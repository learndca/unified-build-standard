# Run log

One line per loop, newest at the bottom. Lines are added, never edited or removed. Times are GMT.

Outcome is one of: **Kept** (check passed, change stays), **Discarded** (check failed or result got worse, change undone), **Blocked** (could not proceed), **Phase done**, **Stopped** (a stop condition was reached), **Complete**.
